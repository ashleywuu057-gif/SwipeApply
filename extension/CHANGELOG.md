# 变更记录

本项目的重要变更记录在此文件中。版本号遵循语义化版本格式。

## [Unreleased]

### Added

- Chrome Manifest V3 本地履历、字段规则和投递记录管理。
- 通用表单以及 Moka、北森 Phoenix、飞书招聘 ATSX 专用适配器。
- 字段扫描、保守匹配、网页控件操作、回读校验和待处理清单。
- 虚构演示页面、118 个单元测试和 52 个 Playwright 扩展端到端测试。
- MIT 许可证、隐私说明、安全策略、贡献指南和 GitHub 项目模板。

### Changed

- 开发工具升级到 Vitest 5、Vite 8、esbuild 0.28、Playwright 1.63 和 TypeScript 7。
- 手动字段重试和整组经历绑定会等待最终异步校验完成后再返回。
- 北森 Phoenix 支持传音配置中的学习形式、生源地、英语等级/成绩、期望工作城市多选地区弹窗、到岗时间、GPA、课题研究、项目职务与成果；多出的整条空白经历在详情页折叠提示。
- “随时/立即到岗”可在网站只提供时间区间时安全选择“一周内”；本轮自动勾选“至今”后，同一记录的禁用结束日期不再重复进入待处理。
- 收紧自定义日期识别，避免把“到岗时间”这类普通枚举下拉误当日历；已勾选“至今”时不再重复报告空结束日期。
- 履历可选择保存证件号码与紧急联系人；这些敏感字段只有在专用站点适配器精确绑定时才能填写，通用页面仍保持待处理。
- 网页要求完整日期时，教育开始日期按 9 月 1 日、毕业日期按 6 月 30 日补全，其他只有年月的日期按当月 1 日补全；履历已有精度始终优先。

### Security

- 生产构建仅使用 `activeTab`、`scripting` 和 `storage` 权限。
- 开发依赖审计结果为 0 个已知漏洞。
