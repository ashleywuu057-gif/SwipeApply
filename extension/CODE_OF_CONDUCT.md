# 社区行为准则

ApplyKit 社区欢迎不同经验、背景和观点的参与者。参与 Issue、Pull Request、讨论和代码评审时，请保持尊重、具体和建设性。

## 期望行为

- 围绕代码、证据和用户影响讨论问题；
- 尊重隐私，主动删除示例中的个人信息和账号数据；
- 接受合理的技术分歧并解释取舍；
- 帮助新贡献者理解复现、测试和项目边界。

## 不可接受的行为

- 骚扰、侮辱、歧视、威胁或持续的人身攻击；
- 未经同意公开他人的身份、履历、联系方式或账号信息；
- 发布垃圾信息、恶意代码或与项目无关的推广；
- 在被要求停止后继续干扰协作。

维护者可以编辑、隐藏或删除违反本准则的内容，并限制相关参与者继续参与。涉及隐私或安全的问题请按 [SECURITY.md](SECURITY.md) 私下报告。
